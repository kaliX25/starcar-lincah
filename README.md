# Star Car LINCAH - Prototype

Prototype mobile app (React Native + Expo) untuk solusi **LINCAH: Star Car Sustainable Mobility**.
Enam layar mewakili pilar Learn, Installment, Next, Charge, Assist, Harvest. Semua data adalah dummy.

```bash
npm install
npm run web      # localhost:8081
npm start        # scan QR dengan Expo Go di HP
```
